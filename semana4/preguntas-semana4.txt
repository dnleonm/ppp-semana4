Preguntas Semana 4

¿Qué es Node.js?

Respuesta:
Un entorno que permite ejecutar JavaScript en el servidor

¿Qué hace el comando npm init?

Respuesta:
Inicializa un proyecto Node.js creando el archivo package.json

¿Qué es Express en Node.js?

Respuesta:
Un framework para construir servidores y APIs en Node.js

¿Qué hace una ruta en una aplicación web?

Respuesta:
Define cómo responde el servidor cuando un usuario accede a una URL
