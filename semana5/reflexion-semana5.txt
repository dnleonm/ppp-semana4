Reflexión Semana 5:

Las APIs pueden ayudar mucho a las comunidades porque permiten compartir información de forma organizada, rápida y accesible. Gracias a las rutas en Express, diferentes personas o aplicaciones pueden consultar mensajes, reportes o alertas utilizando solicitudes HTTP como GET y POST. Esto facilita que la información se mantenga actualizada y centralizada en un solo servidor. Además, las APIs ayudan a automatizar procesos y permiten que diferentes plataformas se comuniquen entre sí utilizando datos estructurados como JSON. En proyectos comunitarios, esto puede servir para reportar problemas, enviar solicitudes o compartir información importante de manera más eficiente. También ayuda a fortalecer la participación ciudadana y la transparencia digital. Finalmente, aprender a construir APIs permite entender cómo funcionan muchas aplicaciones modernas y abre posibilidades para crear herramientas tecnológicas con impacto social.
